3. Description of the App

Sono is a picture-symbol communication app that allows users to express themselves by tapping illustrated symbol cards to build sentences, which the App then reads aloud using text-to-speech technology.

Key features include:

  • A customisable symbol board with hundreds of illustrated categories and vocabulary items.
  • A sentence strip for composing multi-symbol messages.
  • Text-to-speech output using either offline voice models (downloaded on request) or the device’s built-in voice service.
  • Sentence suggestions powered by a deterministic local rule-based engine. Some builds of the App additionally expose a “Bring Your Own Model” path that allows the caretaker to import a GGUF-format language model file and use it locally for sentence suggestions (see Section 8 and Section 11). No language model is bundled with the App.
  • An optional learning area with lessons. Where the build is configured with a remote lessons backend, the App fetches lesson catalog, lesson content, and scene images from that backend over HTTPS and caches them locally for offline replay; otherwise only bundled lessons are available (see Section 8.2 and the Privacy Policy).
  • A caretaker-initiated backup feature that exports caretaker-managed content (custom symbols, custom photos, custom voice recordings, hidden items, quick phrases, and configuration) as a .sonobkp archive, and a corresponding import feature (see Section 8.3).
  • Caretaker settings for personalising symbols, photos, voice recordings, preferred voice, grid layout, and board behaviour.

The App is a communication tool. It is not a substitute for qualified educational support, professional guidance, medical advice, or any other formal service. The caretaker and the user are responsible for determining how the App fits into the user’s broader communication and learning approach.
