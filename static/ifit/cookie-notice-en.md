# iFit Cookie Notice

Last updated: 2026-08-31

This document is an English project draft. Replace the bracketed fields before publication, especially the operator contact details and any deployment-specific third-party storage.

### 1. What this notice covers

This Cookie Notice explains how iFit uses cookies and similar technologies. In
this notice, "cookies" includes browser cookies, local storage, IndexedDB,
Sembast browser storage and similar device storage used by the application.

iFit is a web booking application. It needs some local storage to keep users
signed in, remember consent choices and run securely. The current iFit
implementation does not enable analytics cookies, advertising cookies or
marketing cookies.

If iFit is embedded in another website, the embedding website may use its own
cookies. Those cookies are controlled by that website, not by this iFit Cookie
Notice.

### 3. Essential storage

Essential storage is required for the app to work, for security or to remember
your privacy choices. It cannot be disabled through the iFit cookie preference
panel.

| Name or prefix | Purpose | Typical duration |
| --- | --- | --- |
| `generic_shop_app_ifit-mandatory-cookieConsentMandatory` | Records whether the essential-cookie notice was acknowledged | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-cookieConsentFunctionality` | Records the user's functional-cookie choice | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-cookieConsentStatistics` | Records the user's statistics-cookie choice, even though statistics cookies are not enabled for iFit now | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-cookieConsentMarketing` | Records the user's marketing-cookie choice, even though marketing cookies are not enabled for iFit now | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-version` | Stores the local cache version so the app can migrate or clean local storage safely | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-sessionToken` | Stores the signed-in user's bearer token so the session survives a page refresh | Until sign-out, browser data is cleared or the app cache is reset. The matching server session is designed to expire within 7 days from creation or refresh |
| `generic_shop_app_ifit-mandatory-sessionUser` | Stores limited signed-in user data such as user id, name, e-mail, phone, role, credits and creation date | Until sign-out, browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-deviceId` | If generated by the shared app framework, identifies the browser or device for security and service operation | Until browser data is cleared or the app cache is reset |
| `generic_shop_app_ifit-mandatory-translations` | Used only when translation edit mode is enabled, to cache translation values | Until browser data is cleared or the app cache is reset |

The exact physical storage may be IndexedDB or another browser storage mechanism
chosen by the Flutter/web runtime and the shared app framework.

### 4. Functional storage

Functional storage improves convenience but is not strictly required. iFit's
plugin configuration allows functional cookies, but the current iFit booking
flows do not rely on optional bookmarks, search history, analytics or marketing
storage.

Depending on the shared app shell and deployment settings, optional functional
storage may include preferences such as theme brightness or other local UI
choices. If functional storage is disabled, the core booking service should still
work, but some preferences may not be remembered.

### 5. Statistics and marketing storage

Statistics and marketing cookies are disabled in the current iFit implementation.
iFit does not currently use advertising cookies, cross-site tracking cookies or
analytics cookies for marketing profiling.

If statistics or marketing storage is added later, it should not be used unless
the required consent has been collected and this notice has been updated to name
the relevant provider, purpose and duration.

### 7. Managing choices

You can manage optional cookie choices through the iFit cookie banner or
preference panel where available. Essential storage is required for the service
and cannot be turned off in the app.

You can also clear or block cookies and site data in your browser settings. If
you clear essential iFit storage, you may be signed out and asked to confirm
cookie choices again. If you block all local storage, some parts of iFit may not
work correctly.

Signing out removes the local iFit session token and local signed-in user cache
from the app storage on that device. It does not delete server-side booking,
attendance or account records.
