Guía de uso

Categorías y búsqueda

Cómo se organiza el vocabulario entre pestañas de categoría, subcategorías, sugerencias y búsqueda.

Recientes y pestañas de categorías

La pestaña "Recientes" (mostrada primero) se llena automáticamente con los símbolos que el usuario toca con más frecuencia — se personaliza con el tiempo para que las palabras favoritas siempre estén a mano. Las pestañas de categoría (Básicos, Personas, Emociones, Acciones, Comida, Lugares, Cosas) contienen todo el vocabulario organizado por tema. Empieza por "Básicos" para palabras de respuesta esenciales como "sí", "no" y "ayuda".

Código de colores

Symbol borders use the Modified Fitzgerald Key, a colour system that groups words by grammatical function: Yellow — People (I, you, mom) Green — Actions (go, eat, want) Orange — Nouns (water, bed, ball) Blue — Descriptors (happy, big, hot) Purple — Questions (what, where) Pink — Social (hi, please, thanks) Red — Important (no, stop, help) Over time this helps users recognise word types and build grammatically richer sentences.
