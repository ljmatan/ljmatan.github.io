Kategorier og søgning

Hvordan ordforrådet er organiseret på kategorifaner, underkategorier, forslag og søgning.

Seneste og kategorifaner

Fanen "Seneste" (vises først) udfyldes automatisk med de symboler, brugeren oftest trykker på — den tilpasser sig over tid, så yndlingsord altid er ved hånden. Kategorifanerne (Basis, Personer, Følelser, Handlinger, Mad, Steder, Ting) indeholder hele ordforrådet organiseret efter emne. Start med "Basis" for vigtige svarord som "ja", "nej" og "hjælp".

Farvekodning

Symbol borders use the Modified Fitzgerald Key, a colour system that groups words by grammatical function: Yellow — People (I, you, mom) Green — Actions (go, eat, want) Orange — Nouns (water, bed, ball) Blue — Descriptors (happy, big, hot) Purple — Questions (what, where) Pink — Social (hi, please, thanks) Red — Important (no, stop, help) Over time this helps users recognise word types and build grammatically richer sentences.
