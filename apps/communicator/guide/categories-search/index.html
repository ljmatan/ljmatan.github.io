Usage guide

Categories & search

How vocabulary is organised across category tabs, subcategories, suggestions, and search.

Recents & category tabs

The "Recents" tab (shown first) automatically fills with symbols the user taps most often — it personalises itself over time so favourite words are always at hand. Category tabs (Basics, People, Feelings, Actions, Food, Places, Things) contain the full vocabulary organised by topic. Start with Basics for essential response words like "yes", "no", and "help".

Colour coding

Symbol borders use the Modified Fitzgerald Key, a colour system that groups words by grammatical function: Yellow — People (I, you, mom) Green — Actions (go, eat, want) Orange — Nouns (water, bed, ball) Blue — Descriptors (happy, big, hot) Purple — Questions (what, where) Pink — Social (hi, please, thanks) Red — Important (no, stop, help) Over time this helps users recognise word types and build grammatically richer sentences.
