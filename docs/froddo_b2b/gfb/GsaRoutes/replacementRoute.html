replacementRoute

replacementRoute property

GsaRoute? Function()? Function(GsaRouteType route)? replacementRoute
getter/setter pair

Property used for overriding route displays.

The property can be set by a client plugin in order to return another route as a replacement to this option:

GsaRoutes.replacementRoute = (route) {
  return switch (route) {
    GsaRoutes.userProfile => () => CustomRoute(),
    _ => null,
  };
};
